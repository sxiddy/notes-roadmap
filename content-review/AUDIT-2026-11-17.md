# Audit of every notes site against the owner's rules (17-11-2026)

Read-only audit. Nothing in the site repos was edited, committed, pushed or deployed.

How it was run (same for every site):
- `validate.js` and `syllabus-check.js` ran in the repo (they only read).
- `build.js` and `qa.js` write files into the repo, so they ran on a scratch copy; the fresh build was then
  compared with the committed build files.
- Content checks (syllabus rows, paper links, thin tabs, figures, MCQ keys) came from a script that loads
  `content/*.js` the same way `validate.js` does.
- The live sites sit behind Google sign-in, which the audit cannot pass. The live files were compared with the
  repo build by hash, and the same build was opened locally at 375 px.

Run in two parts: 17-11-2026 (BACHY105, most of BAEEE101, store home page) and 18-11-2026 (EVS, BAENG101,
BAPHY105, store tests). On 18-11 a separate session was still writing BAPHY105, so that section is a snapshot of
commit 8c1e484.
