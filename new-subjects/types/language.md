# Playbook: language (BAESP101 Spanish Level I)

VTOP lists no theory material for this course ("No data available in table"); the lab option was not opened.
Nothing can be drafted until the owner supplies the syllabus and a source (handouts or the prescribed book).
Do not copy a textbook's dialogues or exercises: write original ones on the same grammar points.

## Content format changes
- New content file `content/vocab-<unit>.js`: `VOCAB({ unit, items:[{ es, en, pos, gender:'m'|'f'|null,
  plural, example:{es,en}, tags:['food'] }] })`. Flashcards and battle cards are generated from it by the build.
- New `content/verbs.js`: `{ inf:'hablar', en:'to speak', group:'ar', irregular:false, forms:{ present:
  ['hablo','hablas','habla','hablamos','habláis','hablan'] } }`. Regular forms are generated by script and
  only irregular ones are typed; a script cross-checks both.
- Tabs per unit: Dialogue (two-column Spanish and English, `table.tbl dialogue`), Grammar point, Vocabulary,
  Culture note, Exam practice.
- Question types (B2): `type-in` with accent-tolerant marking (accept without accents but show the correct
  form), `match` (pairs), `order` (jumbled sentence), `cloze` (same schema as `fill`), plus existing MCQ.

## App code to extend
- `tools/build.js`: read vocab and verbs, emit flashcards and `_battle.json` entries, keep answers Pro.
- `tools/validate.js`: schemas; every `es` string uses proper characters (á é í ó ú ñ ü ¿ ¡).
- `app/js/app.js`: `viewCards()` gains spaced repetition (this is N3 in `features-notes/`; build it here
  first); new `viewDrill()` for conjugation and gender/article drills driven by `verbs.js` and `vocab`;
  `qCard()`/`viewQuiz()` for the new types; an on-screen row of accent keys for typed answers.
- Speech: one helper `speak(text)` in `app.js` using `speechSynthesis` with an `es` voice.

## Cost
B2 6% (shared), spaced repetition 8% (N3), drill view and speech 5%. Content: far fewer note pages than a
theory subject; estimate 25-35% for a level-I syllabus, strongest model, with every Spanish sentence checked in
a second pass by a different model family through FreeLLMAPI (check only, as today's rule) and a human who
knows Spanish for one sample unit.

## Quality risks
Wrong gender, accent or conjugation (script-generate regular forms; second-model check); Spain versus Latin
American usage (follow the faculty's variety, including whether vosotros is taught); machine voice mispronouncing;
exam format unknown (written, listening, oral) until the owner confirms.

## Free and Pro
Free: unit 1 complete, all dialogues, 20 vocabulary cards per unit, browser speech.
Pro: full vocabulary with spaced repetition, all drills, exam practice with answers, verb tables sheet.
